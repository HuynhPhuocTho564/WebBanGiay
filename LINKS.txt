----------------------------------------

----------------------------------------

Thêm User:          http://localhost/shop_giay_project/public/adminuser/create

📋 GHI CHÚ
----------------------------------------
- Đảm bảo XAMPP đang chạy (Apache + MySQL)
- Database: shop_giay_db
- Tài khoản Admin mặc định: Cần tạo trong database

🔧 GOOGLE LOGIN SETUP
----------------------------------------
1. Vào: https://console.cloud.google.com/
2. Tạo Project → APIs & Services → Credentials
3. Tạo OAuth Client ID (Web application)
4. Redirect URI: http://localhost/shop_giay_project/public/auth/googleCallback
5. Copy Client ID & Secret vào: config/google_config.php
